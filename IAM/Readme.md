# IAM

This folder contains resources and scripts for working with AWS Identity and Access Management (IAM).

## Contents

- **CreateUserandpolicy**: Script to create IAM users and policies.

## Features

- **IAM Users**: Create and manage IAM users.
- **IAM Policies**: Create and attach policies to IAM users.

## Usage

To create an IAM user and attach a policy, run the following script:

```sh
./CreateUserandpolicy
