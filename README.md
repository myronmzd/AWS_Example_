# AWS Example Project

## Description
This project demonstrates how to build a scalable and serverless web application using AWS services. It is designed as a beginner-friendly guide, showing how to deploy a Flask web app that displays Bible verses stored in DynamoDB. The application leverages AWS services such as API Gateway, Lambda, S3, Route 53, and Polly for a seamless cloud-native experience.

## Features
- Serverless architecture built with AWS Lambda
- RESTful API using Amazon API Gateway
- Static file hosting with Amazon S3
- Custom domain management via Route 53
- Text-to-speech functionality using Amazon Polly
- DynamoDB integration for fast and reliable data storage
- Example code for deploying and managing AWS infrastructure
