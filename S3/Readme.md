# S3

This folder contains resources and scripts for working with Amazon S3.

## Contents

- **bash-scritps/sys**: Bash script to sync files to an S3 bucket.

## Features

- **S3 Sync**: Sync local files to an S3 bucket.

## Usage

To sync files to an S3 bucket, run the following script:

```sh
./bash-scritps/sys <bucket-name> <folder-name>
