# Lambda

This folder contains resources and scripts for working with AWS Lambda.

## Contents

- **lambda-sam-app**: Serverless Application Model (SAM) project for AWS Lambda functions.

## Features

- **Lambda Functions**: Create and deploy Lambda functions using SAM.
- **API Gateway**: Integrate Lambda functions with API Gateway.

## Usage

To build and deploy the Lambda functions using SAM, run the following commands:

```sh
cd lambda-sam-app
sam build
sam deploy --guided
